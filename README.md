
# CloudNotify — Serverless Notification System

CloudNotify is a serverless AWS application designed to process
form submissions and send automated email and SMS notifications.

## Planned Architecture

- Amazon S3 — frontend hosting
- Amazon API Gateway — HTTP API
- AWS Lambda — request processing
- AWS Step Functions — workflow orchestration
- Amazon SES — email notifications
- Amazon SNS — SMS notifications
- Amazon CloudWatch — logging and monitoring

## Project Status

Initial setup and repository preparation.

## Security

- Never commit AWS access keys, secret keys, or session tokens.
- Use IAM roles and least-privilege permissions.
- Validate form submissions on the backend.
- Monitor notification usage and AWS costs.

## Implementation

The architecture and features will be documented and updated as components are implemented and tested.
